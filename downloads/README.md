# Downloads

Put the signed + notarized Safari build here as **marco-safari.dmg** — that's the
path safari.html's "Download for Safari" button points to.

Build it with the marco repo's scripts/build-safari.sh + Xcode, then sign,
notarize, and package per marco/docs/safari-install.md (Part 2). Drop the .dmg
here, commit, and push to deploy the live download.
